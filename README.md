AI Code Reviewer Backend

AI-powered backend service that analyzes source code and provides automated code review suggestions using LLMs.

**Features:**
AI-based code analysis
Detects bugs and bad practices
Suggests code improvements
REST API built with Node.js and Express

**Tech Stack:**
Node.js
Express.js
Gemini API
JavaScript

**Installation:**

git clone https://github.com/rishabh0303/ai-code-reviewer-backend.git
cd ai-code-reviewer-backend
npm install
